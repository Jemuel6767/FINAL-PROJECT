# StudyHub Submission Checklist

- [x] NestJS backend builds.
- [x] MySQL connection works locally.
- [x] JWT authentication and bcrypt hashing implemented.
- [x] At least two CRUD modules implemented.
- [x] At least 20 routes mapped.
- [x] Manual demo teacher seed procedure included (`npm.cmd run seed:demo`).
- [x] `.gitignore` excludes `.env`, `node_modules`, `dist`, and uploads.
- [ ] Complete Postman run and screenshots.
- [ ] Export actual `studyhub_db.sql`.
- [ ] Initialize Git and create five meaningful commits.
- [ ] Create/publish GitHub repository and copy link.
- [ ] Add student name and links to documentation.
- [ ] Convert documentation to PDF.
- [ ] Prepare and record 5–10 minute video.
- [ ] Prepare final presentation slides.
